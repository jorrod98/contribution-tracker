# Contributing

Thanks for considering a contribution! Small, focused changes are a great fit.
If you're unsure about an idea, open an issue before doing a lot of work.

## Development setup

1. Fork the repository and clone your fork.
2. Create a branch for your change.
3. Make your change and add or update tests.
4. Run the tests:

   ```bash
   python3 -m unittest discover -s tests -v
   ```

5. Open a pull request describing what changed and how you tested it.

The app uses only the Python standard library. Keep changes straightforward and
avoid adding dependencies without discussing them in an issue first.

## Pull requests

- Keep each pull request focused on one issue or improvement.
- Include tests for behavior changes.
- Be kind and constructive in discussion and review.
